## 🚀 Featured projects

### 🔎 Hybrid AI Visual Search
*Python · OpenCV · SIFT · YOLOv8 · Streamlit*

Upload a large source image and a small input image (such as a logo). The app finds every copy of
the logo in the big picture, detects faces and categorises the objects it sees.

- Combines **SIFT feature matching + RANSAC**, **colour/shape matching** for flat logos and **multi-scale template matching**
- Detects faces (YuNet / Haar cascades) and groups them by size and position
- Categorises objects with **YOLOv8** (People, Vehicles, Electronics, …)
- Streamlit UI with annotated output, CSV / JSON export and a ZIP of all cropped results

🔗 [Repository](https://github.com/Rishitghosh340/Hybrid_AI_Visual_Search)

### 🎯 Template Matching with Edge Detection — Computer Vision Pipeline
*Python · OpenCV · NumPy · Matplotlib · 2024*

An end-to-end pipeline that detects and localises objects within images.

- Preprocessing with **Gaussian blurring and Canny edge detection** to reduce noise and sharpen object boundaries
- **Benchmarked all six OpenCV template-matching methods** (`TM_CCOEFF`, `TM_CCORR`, `TM_SQDIFF`, …) to find the most accurate and efficient one
- Visualised the best matches with bounding boxes using `cv2.minMaxLoc()`

🔗 [Repository](https://github.com/Rishitghosh340/Template-Matching)

### 🍽️ Restaurant Reservation System — MERN Stack Web App
*React (Vite) · Node.js · Express · MongoDB · Mongoose*

A full-stack reservation platform with a React front end and a REST API backend.

- **Mongoose schema** with server-side validation for name length, email format and phone number
- `POST /api/v1/reservation/send` endpoint with **centralised error-handling middleware** that returns descriptive validation errors
- **Axios**, **React Router** and **react-hot-toast** for navigation and real-time submission feedback
- **CORS** and environment-based configuration; front end and back end are independently deployable
